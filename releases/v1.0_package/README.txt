OpenWirelessMC v1.0 by Schickacka
====================================

Como usar:
1. Grave o firmware no ESP32 usando flash_windows.bat (ou via PlatformIO).
2. Extraia o conteudo de sdcard_assets.zip (titles.db, default.mc, config.txt)
   na raiz de um cartao MicroSD formatado em FAT32.
3. Edite config.txt com seu Wi-Fi (ou use o modo Ponto de Acesso padrao).
4. Insira o MicroSD e ligue no PlayStation 1 ou 2!
