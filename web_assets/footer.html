🎮 Troca Automática de Jogo (Auto GameID Switch)

O OpenWirelessMC possui compatibilidade direta com comandos seriais de identificação de jogo (como no PicoStation ODE).

  • Boot Padrão: Ao ligar o console sem lançar nenhum jogo, o sistema monta automaticamente default.mc no Slot 1.
  • Troca em Tempo Real: Ao iniciar qualquer jogo pelo menu de um ODE, o console envia automaticamente o Game ID oficial (exemplo: SLUS-01334 ou SCUS-94183).
  • Criação Automática: O OpenWirelessMC intercepta esse comando e engata imediatamente <GAME_ID>.mc no Slot 1. Se o arquivo ainda não existir, uma nova imagem formatada de 128KB é criada instantaneamente no MicroSD!
  • Cada jogo possui seu próprio cartão virtual dedicado, com slots ilimitados!
⏏️ Desmontagem e Ejeção Virtual de Memory Card

No banner superior de Save Ativo, há o botão ⏏ Desmontar / Ejetar. Ele desabilita a emulação do barramento e esvazia a ranhura de forma totalmente segura no hardware. É perfeito para batalhas como a do Psycho Mantis no Metal Gear Solid, onde o chefe tenta ler seus pensamentos através dos seus saves!

💾 Formato, Restrições e Compatibilidade
Padrão PS1 (128 KB)
Imagens padrão de PlayStation 1 têm exatamente 131.072 bytes (128 KB) com 16 quadros de 8KB (1 cabeçalho + 15 blocos). Formatações feitas pela web criam a estrutura oficial da Sony.
Suporte e Saves PS2 (8 MB)
O gerenciador suporta armazenamento e upload de saves de PlayStation 2 (8 MB). No painel de status você acompanha o espaço para ambos os consoles.
Regras de Nomes de Arquivo
Nomes de arquivo não devem conter espaços nem caracteres proibidos (/ \ : * ? " < > |). A extensão .mc é adicionada automaticamente caso omitida.
🔄 Como Usar Saves de Emuladores (DuckStation / PCSX / MemcardRex)
  1. Exporte o arquivo de Memory Card do emulador (formatos .mc, .mcr, .mcd de 128 KB).
  2. Renomeie o arquivo se preferir (ex: SLUS-01334.mc ou Tekken3.mc).
  3. Abra a aba Saves & Arquivos e selecione o arquivo em Enviar Save Existente.
  4. Clique em ✖ Enviar Save. O save já estará no MicroSD do console!
  5. Para usá-lo imediatamente, clique em ▲ Montar na tabela.
