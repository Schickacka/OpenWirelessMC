🎮 Integração com o PicoStation ODE (Auto GameID)

O OpenMC possui compatibilidade direta e nativa com o PicoStation ODE via comando serial SIO 0x21.

  • Ao iniciar qualquer jogo pelo menu do PicoStation, o console envia automaticamente o Game ID oficial (exemplo: SLUS-00005 ou SCUS-94183).
  • O OpenMC intercepta esse comando e engata imediatamente o cartão virtual <GAME_ID>.mc no Slot 1.
  • Se você estiver jogando aquele game pela primeira vez e o arquivo não existir no MicroSD, o OpenMC cria instantaneamente uma imagem formatada virgem de 128KB!
  • Isso garante que cada jogo tenha seu próprio Memory Card virtual de 15 blocos dedicados, sem limites de espaço!
💾 Formato e Estrutura dos Arquivos de Save
Tamanho Exato: 128 KB
O PlayStation 1 requer imagens com tamanho exato de 131.072 bytes (128 KB). Elas contêm 16 quadros de 8KB (1 quadro de diretório/cabeçalho + 15 blocos utilizáveis).
Extensões Compatíveis
Arquivos com extensões .mc, .mcr e .mcd são reconhecidos nativamente. O padrão do OpenMC é .mc.
🔄 Como Usar Saves de Emuladores (DuckStation / Mednafen / MemcardRex)
  1. Exporte ou localize o arquivo de Memory Card do emulador no seu computador (ele deve ter 128 KB).
  2. Renomeie o arquivo para o formato desejado, preferencialmente o Game ID do jogo (ex: SLUS-00005.mc para Crash Bandicoot).
  3. Acesse esta interface pelo navegador, abra a aba Saves & Arquivos e selecione o arquivo no formulário de envio.
  4. Clique em ✖ Enviar Save. O arquivo estará salvo no MicroSD do seu PS1!
  5. Para forçar o carregamento imediato no console, basta clicar no botão ▲ Montar na tabela.
🛡️ Boas Práticas e Dicas de Segurança
  • Backups Simples: Baixe periodicamente seus arquivos .mc clicando no nome deles na tabela para guardar uma cópia segura no seu computador ou na nuvem.
  • Nunca Desligue Durante a Gravação: Quando um jogo do PS1 estiver salvando ("Salvando... Não desligue o console"), aguarde a mensagem de confirmação antes de desligar o console. O OpenMC grava os dados na memória RAM e sincroniza com o MicroSD logo em seguida.
  • Organização: Pastas com o nome do Game ID são criadas automaticamente para organizar títulos multidiscos ou backups especiais.
